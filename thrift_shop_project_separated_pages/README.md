# Thrift Shop — Student Website Project

A responsive thrift-store website concept designed with a student-friendly, East African campus feel. It uses HTML, CSS and vanilla JavaScript, so it is easy to explain and edit for coursework.

## Separate pages included
- Home (`index.html`) / hero section
- Shop (`shop.html`) with category filters: Clothing, Shoes, Bags and Accessories
- About Us (`about.html`)
- Gallery (`gallery.html`)
- FAQ (`faq.html`)
- Contact form (`contact.html`)
- Responsive navigation menu

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a web browser. Each main section now has its own HTML page; shared styling and existing content are preserved. For development, VS Code with the Live Server extension is recommended.
3. Internet access is needed for the remote product photos and Google Fonts.

## Before submitting
- Replace the sample contact details with your own approved project contact details.
- Replace sample listings/prices with your own if required.
- Test the mobile layout and take screenshots of Home, Shop, About, Gallery, FAQ and Contact.
- Add those screenshots and your deployed website URL to your course-work PDF.
- The contact form is a front-end demo. It does not send messages until connected to a backend or form service.
- Images are loaded from Unsplash URLs; for a final submission, make sure you are happy with the selected image licensing and availability.

## Deploy to Netlify
1. Sign in to Netlify.
2. Choose **Add new site** / **Deploy manually** (wording may vary).
3. Drag the extracted project folder (the folder containing `index.html`, `style.css`, and `script.js`) into the deploy area.
4. Wait for the deploy to finish, then copy your public site URL into your report.
5. Open the URL on your phone and laptop to check it.

## Suggested project title
**Thrift Shop: A Student-Friendly Online Thrift Store**

## Problem being addressed
Students and budget-conscious shoppers may find it difficult to discover affordable, individual clothing and accessories in one place. This demo provides a simple online catalogue, category filtering, product enquiry prompts and store information. It is a front-end prototype and does not process payments or manage real stock.
